# Top-Down Parser Lab — Technology Stack

## Presentation-ready summary

**Language:** TypeScript

**Frontend framework:** React 19

**Build tool:** Vite 7

**Styling:** Tailwind CSS 4 with custom CSS design tokens

**UI icons:** Lucide React

**Client-side routing:** Wouter

**Testing:** Vitest

**Deployment:** GitHub Pages through GitHub Actions

## What the application does

- Visualizes Recursive Descent Parsing (RDP)
- Computes FIRST and FOLLOW sets
- Builds and traces LL(1) predictive parsing tables
- Detects and automatically eliminates direct and indirect left recursion
- Supports epsilon productions and explanatory parser traces

## PPT sentence
