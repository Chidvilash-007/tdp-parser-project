# Top-Down Parser Lab — Save and run locally

This folder contains the complete source code for the interactive parser visualizer.

## Easiest option: keep the ZIP

Download the ZIP file provided with this project and save it somewhere safe, such as your Desktop or Documents folder. You can copy it to a USB drive or cloud storage like Google Drive.

## If you want to run the project on your own computer

1. Install **Node.js 22 or newer** from https://nodejs.org/.
2. Extract the ZIP file.
3. Open a terminal inside the extracted `topdown-parser-lab` folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local address shown in the terminal, usually `http://localhost:3000`.

## Windows tip

In File Explorer, open the extracted project folder, click the address bar, type `cmd`, and press Enter. Then run the commands above.

## Important

- Do not delete `package.json`, `client/`, `shared/`, or `vite.config.ts`.
- The `node_modules` folder is created automatically after `npm install`; it does not need to be included in the ZIP.
- The app works without a database or API key.
